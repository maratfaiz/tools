# Higgsfield — генерация картинок/видео в Claude Code

## Что это простыми словами

Higgsfield — облачный сервис, который по текстовому описанию (или по фото/видео-референсу) рисует картинку, снимает видео, лепит 3D-модель или генерирует звук — примерно как Midjourney/Runway, но с одной моделью на всё сразу (картинки, видео, 3D, аудио) и с готовыми «рецептами» под конкретные задачи (реклама, брендбук, превью для YouTube).

**Зачем это в Claude Code:** без Higgsfield, если попросить «сделай мне баннер для лендинга», Claude умеет только *написать код*, который что-то нарисует (SVG, canvas) — реального изображения не будет. С Higgsfield Claude может прямо попросить внешний сервис сгенерировать настоящую картинку/видео и вставить готовый файл/ссылку в ответ.

Есть два независимых способа этим пользоваться — они не конкурируют, можно и нужно оба.

## Способ 1 — просто попросить словами (MCP, работает сразу)

Это самый простой путь. В Claude Code подключён Higgsfield MCP-сервер — набор готовых «кнопок», к которым Claude обращается напрямую, без терминала, без установки, без логина (уже авторизован под твоим аккаунтом).

**Как пользоваться:** пишешь обычную фразу, никаких специальных команд не нужно:

```
Сделай картинку заката над городом в стиле киберпанк
Сделай видео, как эта фотка оживает и человек поворачивает голову
Убери фон с этой картинки
Увеличь это видео до 4K
Расширь эту картинку так, чтобы она стала горизонтальной (uncrop)
Оцени, насколько виральным получится это видео — где проседает внимание?
Покажи, что я уже генерировал сегодня
```

Claude сам понимает, какой из инструментов вызвать. Полный список того, что доступно «под капотом» — на случай, если хочешь попросить точнее:

| Инструмент | Что делает |
|---|---|
| `generate_image` / `generate_image_batch` | генерация картинок (одна или пачкой) |
| `generate_video` / `generate_video_batch` | генерация видео |
| `generate_audio` / `generate_audio_batch` | генерация звука/музыки |
| `generate_3d` | картинка → 3D модель (GLB) |
| `upscale_image` / `upscale_video` | апскейл до 2K/4K |
| `outpaint_image` | расширение картинки за края (uncrop) |
| `reframe` | смена соотношения сторон видео (например 16:9 → 9:16 для Reels) |
| `remove_background` | вырезка фона |
| `motion_control` | перенос движения с одного видео на другой референс |
| `virality_predictor` | оценка виральности готового видео (хук, удержание внимания, слабые места) |
| `show_generations` / `job_display` | посмотреть историю генераций |
| `balance` / `show_plans_and_credits` | баланс и тарифы |

**Когда этого достаточно:** для разовых запросов — «сделай мне картинку X», «оживи это фото», «убери фон». Для больших многошаговых задач (полноценный рекламный ролик с продуктом и аватаром, полный брендбук) — там нужен способ 2, потому что для них нужна последовательность из многих шагов и выбора, которую способ 1 не покрывает по одной фразе.

## Способ 2 — CLI + специализированные skills (для сложных многошаговых задач)

В этом репозитории уже установлены skills, которые учат Claude Code пользоваться терминальным CLI `higgsfield` (короткие алиасы: `higgs`, `hf`). Каждый skill — это инструкция под конкретный сложный сценарий, где одной фразы недостаточно и нужен пошаговый процесс (выбрать модель → загрузить референсы → сгенерировать → собрать результат).

| Skill | Когда активируется | Пример запроса |
|---|---|---|
| **higgsfield-generate** | универсальная генерация картинок/видео/3D/аудио, рекламные ролики (Marketing Studio), анализ виральности | «Сделай рекламное видео для моего приложения с аватаром-презентером» |
| **higgsfield-brandkit** | полный брендбук с нуля | «Сделай мне логотип, палитру и брендбук для кофейни» |
| **higgsfield-product-photoshoot** | предметная съёмка товара | «Сделай студийное фото моих кроссовок на белом фоне» |
| **higgsfield-marketplace-cards** | карточки товара под Wildberries/Ozon/Amazon | «Сделай главное и дополнительные фото товара под маркетплейс» |
| **higgsfield-youtube-thumbnail** | превью для YouTube/Shorts | «Сделай кликабельный тамбнейл для этого видео про...» |
| **higgsfield-soul-id** | обучение модели на конкретном лице (один раз) | «Обучи модель на моих фото, чтобы дальше генерировать с моим лицом» |
| **higgsfield-video-explainer** | озвученное объясняющее видео из блоков | «Сделай 2-минутное видео, объясняющее, как работает блокчейн» |
| **higgsfield-websites** | сборка и деплой сайтов/приложений/игр | «Собери и задеплой лендинг для этого продукта» |

Активировать вручную не нужно — они лежат в `.claude/skills/*` и Claude Code подхватывает их сам, когда видит подходящий запрос. Просто формулируй задачу как в примерах справа.

### Установка (для справки — на своей машине, если Claude Code работает не только здесь)

```bash
npm i -g @higgsfield/cli       # ставим CLI
higgsfield auth login          # логин через браузер (нужен локальный браузер!)
npx skills add higgsfield-ai/skills   # ставим skills в текущий репозиторий
```

**Важно про `auth login`:** это OAuth-логин через браузер с обратным вызовом на `localhost` — он работает только там, где у тебя одновременно есть браузер и терминал (свой компьютер). Из облачной/удалённой сессии Claude Code (где нет своего браузера) залогинить CLI не получится — но это и не обязательно, для этого есть способ 1 (MCP), который уже авторизован под твоим аккаунтом.

### Базовые команды CLI напрямую (если хочешь руками, а не через Claude)

```bash
higgsfield model list --video          # список видео-моделей
higgsfield model list --image          # список картиночных моделей
higgsfield workflow list               # список готовых воркфлоу
higgsfield generate create <model> --prompt "закат над городом" --wait   # генерация, дождаться результата
higgsfield generate list --json        # история генераций
higgsfield account status              # проверить, авторизован ли
```

`--wait` — команда сама подождёт, пока генерация закончится, и напечатает ссылку на результат, вместо того чтобы отдельно проверять статус.

## Справочник команд

### MCP-инструменты (Способ 1 — вызываются словами, без терминала)

#### `generate_image`
- **Что делает:** генерирует одну картинку по текстовому описанию (+ опционально референс-изображение).
- **Параметры:** текстовый промпт; опционально — референс-картинка, соотношение сторон, разрешение, модель.
- **Пример фразы:** «сделай картинку неонового города ночью, 16:9»
- **Когда использовать:** один раз, разовая картинка.

#### `generate_image_batch`
- **Что делает:** то же самое, но сразу пачкой — несколько вариантов или несколько разных промптов за один заход.
- **Пример фразы:** «сделай 4 варианта логотипа в разных стилях»
- **Когда использовать:** нужно сравнить несколько вариантов сразу, а не генерировать по одному.

#### `generate_video`
- **Что делает:** генерирует видео по тексту или по стартовому изображению (image-to-video).
- **Параметры:** промпт; опционально — стартовый кадр, длительность, разрешение, aspect ratio.
- **Пример фразы:** «оживи эту фотку — пусть человек повернёт голову и улыбнётся»
- **Когда использовать:** разовое видео.

#### `generate_video_batch`
- **Что делает:** несколько видео за один заход (пачка).
- **Пример фразы:** «сделай 3 коротких видео-варианта для этого продукта»

#### `generate_audio` / `generate_audio_batch`
- **Что делает:** генерация звука, музыки, озвучки по тексту (не для готовой речи — для звукового оформления/музыки).
- **Пример фразы:** «сделай фоновую музыку для видео, спокойную, эмбиент»

#### `generate_3d`
- **Что делает:** превращает картинку в 3D-модель (файл GLB), которую можно открыть в 3D-редакторе.
- **Пример фразы:** «сделай 3D-модель из этой картинки товара»

#### `upscale_image` / `upscale_video`
- **Что делает:** увеличивает разрешение готовой картинки/видео до 2K/4K без потери качества.
- **Пример фразы:** «увеличь это видео до 4K»

#### `outpaint_image`
- **Что делает:** «uncrop» — расширяет картинку за существующие края, достраивая содержимое вокруг (например квадратную картинку → в широкий формат).
- **Пример фразы:** «расширь эту картинку, чтобы она стала 16:9»

#### `reframe`
- **Что делает:** меняет соотношение сторон готового видео (например 16:9 → 9:16 под Reels/Shorts) с умной перекомпоновкой кадра, а не простой обрезкой.
- **Пример фразы:** «сделай из этого видео вертикальную версию для Reels»

#### `remove_background`
- **Что делает:** вырезает фон с картинки, оставляя объект на прозрачном фоне.
- **Пример фразы:** «убери фон с этого фото товара»

#### `motion_control`
- **Что делает:** переносит движение/анимацию с одного видео-референса на другой объект/персонажа.
- **Пример фразы:** «перенеси это движение танца на этого персонажа»

#### `virality_predictor`
- **Что делает:** анализирует готовое видео и даёт оценку: общий балл, пиковую секунду удержания внимания (hook), сильные/слабые зоны, риск «потери фокуса».
- **Вход:** одно загруженное видео.
- **Пример фразы:** «оцени, насколько виральным получится это видео»

#### `show_generations` / `job_display`
- **Что делает:** показывает историю твоих генераций (список или детали одной конкретной).
- **Пример фразы:** «покажи, что я генерировал сегодня»

#### `balance` / `show_plans_and_credits`
- **Что делает:** баланс кредитов и информация о текущем тарифе.
- **Пример фразы:** «сколько у меня осталось кредитов»

### CLI-команды (Способ 2 — терминал, после `higgsfield auth login`)

#### `higgsfield auth login`
- **Что делает:** OAuth-логин через браузер, сохраняет токен локально.
- **Синтаксис:** `higgsfield auth login`
- **Когда использовать:** один раз при первой настройке на своей машине. Не работает в облачной сессии без браузера.

#### `higgsfield account status`
- **Что делает:** проверяет, авторизован ли CLI и под каким аккаунтом.
- **Синтаксис:** `higgsfield account status`

#### `higgsfield model list`
- **Что делает:** печатает список доступных моделей.
- **Синтаксис:** `higgsfield model list [--video|--image|--audio]`
- **Пример:** `higgsfield model list --video`
- **Связанная команда:** `higgsfield model get <model_id>` — полная схема параметров конкретной модели (что обязательно, что опционально).

#### `higgsfield workflow list`
- **Что делает:** список готовых многошаговых воркфлоу (например `draw_to_video`, `reframe`) — в отличие от обычных моделей, воркфлоу — это целый сценарий из нескольких шагов.
- **Синтаксис:** `higgsfield workflow list`
- **Связанная команда:** `higgsfield workflow get <name>` — параметры конкретного воркфлоу.

#### `higgsfield generate create`
- **Что делает:** основная команда генерации — отправляет задачу на конкретной модели.
- **Синтаксис:** `higgsfield generate create <model_id> --prompt "..." [медиа-флаги] [параметры модели] [--wait] [--json]`
- **Ключевые флаги:**
  - `--prompt "текст"` — описание
  - `--image <путь-или-id>` / `--video <путь-или-id>` / `--audio <путь-или-id>` — референсы (путь к локальному файлу или id предыдущей загрузки/генерации)
  - `--aspect_ratio 16:9` / `--resolution 2k` / `--duration 10` — параметры (разные модели принимают разные; узнать точный набор — `higgsfield model get <model_id>`)
  - `--wait` — не возвращать управление, пока генерация не завершится, и напечатать готовый результат
  - `--json` — машиночитаемый вывод вместо обычного текста
- **Пример:** `higgsfield generate create gpt_image_2 --prompt "неоновый город" --aspect_ratio 16:9 --resolution 2k --wait`

#### `higgsfield generate list`
- **Что делает:** история генераций.
- **Синтаксис:** `higgsfield generate list [--json]`

#### `higgsfield generate get <id>` / `higgsfield generate wait <id>`
- **Что делает:** `get` — детали одной генерации по id; `wait` — дождаться завершения задачи, запущенной без `--wait` (не дублирует job, просто подключается к уже идущей).

#### `higgsfield voices list`
- **Что делает:** список доступных голосов для озвучки/замены голоса.
- **Синтаксис:** `higgsfield voices list [--json]`

#### `higgsfield preset list` / `higgsfield preset resolve`
- **Что делает:** `list` — показывает готовые пресеты стиля (например для video-explainer); `resolve <preset_id>` — подтягивает конкретный пресет в рабочую область перед использованием.
- **Синтаксис:** `higgsfield preset list <категория> --json` → `higgsfield preset resolve <категория> "<preset_id>" --json`

#### `higgsfield upload create`
- **Что делает:** загружает локальный файл на сервер и возвращает id, который потом можно передавать в `--image`/`--video`/`--audio` других команд вместо пути к файлу.
- **Синтаксис:** `higgsfield upload create <путь-к-файлу>`

> Marketing Studio (рекламные ролики, аватары, продукты, хуки) и `website` — это отдельные большие подсистемы со своими командами (`higgsfield marketing-studio avatars/products/hooks/settings list`, `higgsfield website …`). Они нужны редко и подробно описаны внутри самого skill'а `higgsfield-generate` (`.claude/skills/higgsfield-generate/SKILL.md` и `references/`), который Claude подгружает сам, когда задача требует именно их — незачем держать весь этот справочник здесь.
