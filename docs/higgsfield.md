# Higgsfield — генерация картинок/видео в Claude Code

## Что это простыми словами

Higgsfield — облачный сервис, который по текстовому описанию (или по фото/видео-референсу) рисует картинку, снимает видео, лепит 3D-модель или генерирует звук — примерно как Midjourney/Runway, но с одной моделью на всё сразу (картинки, видео, 3D, аудио) и с готовыми «рецептами» под конкретные задачи (реклама, брендбук, превью для YouTube).

**Зачем это в Claude Code:** без Higgsfield, если попросить «сделай мне баннер для лендинга», Claude умеет только *написать код*, который что-то нарисует (SVG, canvas) — реального изображения не будет. С Higgsfield Claude может прямо попросить внешний сервис сгенерировать настоящую картинку/видео и вставить готовый файл/ссылку в ответ.

Есть два независимых способа этим пользоваться — они не конкурируют, можно и нужно оба.

## Способ 1 — просто попросить словами (MCP, работает сразу)

Это самый простой путь. В Claude Code подключён Higgsfield MCP-сервер — набор готовых «кнопок», к которым Claude обращается напрямую, без терминала, без установки, без логина (уже авторизован под твоим аккаунтом).

**Как пользоваться:** пишешь обычную фразу, никаких специальных команд не нужно:

```
Сделай картинку заката над городом в стиле киберпанк
Сделай видео, как эта фотка оживает и человек поворачивает голову
Убери фон с этой картинки
Увеличь это видео до 4K
Расширь эту картинку так, чтобы она стала горизонтальной (uncrop)
Оцени, насколько виральным получится это видео — где проседает внимание?
Покажи, что я уже генерировал сегодня
```

Claude сам понимает, какой из инструментов вызвать. Полный список того, что доступно «под капотом» — на случай, если хочешь попросить точнее:

| Инструмент | Что делает |
|---|---|
| `generate_image` / `generate_image_batch` | генерация картинок (одна или пачкой) |
| `generate_video` / `generate_video_batch` | генерация видео |
| `generate_audio` / `generate_audio_batch` | генерация звука/музыки |
| `generate_3d` | картинка → 3D модель (GLB) |
| `upscale_image` / `upscale_video` | апскейл до 2K/4K |
| `outpaint_image` | расширение картинки за края (uncrop) |
| `reframe` | смена соотношения сторон видео (например 16:9 → 9:16 для Reels) |
| `remove_background` | вырезка фона |
| `motion_control` | перенос движения с одного видео на другой референс |
| `virality_predictor` | оценка виральности готового видео (хук, удержание внимания, слабые места) |
| `show_generations` / `job_display` | посмотреть историю генераций |
| `balance` / `show_plans_and_credits` | баланс и тарифы |

**Когда этого достаточно:** для разовых запросов — «сделай мне картинку X», «оживи это фото», «убери фон». Для больших многошаговых задач (полноценный рекламный ролик с продуктом и аватаром, полный брендбук) — там нужен способ 2, потому что для них нужна последовательность из многих шагов и выбора, которую способ 1 не покрывает по одной фразе.

## Способ 2 — CLI + специализированные skills (для сложных многошаговых задач)

В этом репозитории уже установлены skills, которые учат Claude Code пользоваться терминальным CLI `higgsfield` (короткие алиасы: `higgs`, `hf`). Каждый skill — это инструкция под конкретный сложный сценарий, где одной фразы недостаточно и нужен пошаговый процесс (выбрать модель → загрузить референсы → сгенерировать → собрать результат).

| Skill | Когда активируется | Пример запроса |
|---|---|---|
| **higgsfield-generate** | универсальная генерация картинок/видео/3D/аудио, рекламные ролики (Marketing Studio), анализ виральности | «Сделай рекламное видео для моего приложения с аватаром-презентером» |
| **higgsfield-brandkit** | полный брендбук с нуля | «Сделай мне логотип, палитру и брендбук для кофейни» |
| **higgsfield-product-photoshoot** | предметная съёмка товара | «Сделай студийное фото моих кроссовок на белом фоне» |
| **higgsfield-marketplace-cards** | карточки товара под Wildberries/Ozon/Amazon | «Сделай главное и дополнительные фото товара под маркетплейс» |
| **higgsfield-youtube-thumbnail** | превью для YouTube/Shorts | «Сделай кликабельный тамбнейл для этого видео про...» |
| **higgsfield-soul-id** | обучение модели на конкретном лице (один раз) | «Обучи модель на моих фото, чтобы дальше генерировать с моим лицом» |
| **higgsfield-video-explainer** | озвученное объясняющее видео из блоков | «Сделай 2-минутное видео, объясняющее, как работает блокчейн» |
| **higgsfield-websites** | сборка и деплой сайтов/приложений/игр | «Собери и задеплой лендинг для этого продукта» |

Активировать вручную не нужно — они лежат в `.claude/skills/*` и Claude Code подхватывает их сам, когда видит подходящий запрос. Просто формулируй задачу как в примерах справа.

### Установка (для справки — на своей машине, если Claude Code работает не только здесь)

```bash
npm i -g @higgsfield/cli       # ставим CLI
higgsfield auth login          # логин через браузер (нужен локальный браузер!)
npx skills add higgsfield-ai/skills   # ставим skills в текущий репозиторий
```

**Важно про `auth login`:** это OAuth-логин через браузер с обратным вызовом на `localhost` — он работает только там, где у тебя одновременно есть браузер и терминал (свой компьютер). Из облачной/удалённой сессии Claude Code (где нет своего браузера) залогинить CLI не получится — но это и не обязательно, для этого есть способ 1 (MCP), который уже авторизован под твоим аккаунтом.

### Базовые команды CLI напрямую (если хочешь руками, а не через Claude)

```bash
higgsfield model list --video          # список видео-моделей
higgsfield model list --image          # список картиночных моделей
higgsfield workflow list               # список готовых воркфлоу
higgsfield generate create <model> --prompt "закат над городом" --wait   # генерация, дождаться результата
higgsfield generate list --json        # история генераций
higgsfield account status              # проверить, авторизован ли
```

`--wait` — команда сама подождёт, пока генерация закончится, и напечатает ссылку на результат, вместо того чтобы отдельно проверять статус.
