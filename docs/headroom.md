# Headroom — сжимает контекст, который читает Claude (меньше токенов)

[github.com/headroomlabs-ai/headroom](https://github.com/headroomlabs-ai/headroom) — локальная «прослойка сжатия» перед AI-агентом. Не отдельная нейронка и не замена Claude — это прокси/библиотека, которая на лету сжимает всё, что агент читает (вывод инструментов, логи, куски RAG, файлы, историю переписки) **перед** тем, как это уйдёт в LLM. Ответы те же, токенов уходит в разы меньше.

**Цифры из их бенчмарков:** поиск по коду −92%, разбор инцидента −92%, разбор GitHub issue −73%, обход кодовой базы −47% токенов, без потери точности на стандартных бенчмарках (GSM8K, TruthfulQA и т.д.).

**Работает с обычной подпиской на Claude.** Это не API-сервис и не нужен отдельный ключ — Headroom просто перехватывает трафик, который Claude Code и так уже шлёт в Anthropic API (или другому провайдеру), сжимает его, и пропускает дальше. Всё считается локально, у тебя на машине — данные никуда не уходят.

## Что установлено сейчас

CLI `headroom` (v0.37.0) уже стоит в этом облачном окружении (`uv tool install "headroom-ai[all]"`), для проверки — `headroom doctor` отрабатывает и корректно показывает, что прокси/обёртка пока не включены. **Реальной пользы это здесь не даёт**: Headroom работает, либо (а) запуская локальный прокси-процесс, который должен крутиться всё время сессии, либо (б) регистрируя MCP-сервер в твоём личном `~/.claude.json` — то и другое живёт на конкретной машине, а не в этой одноразовой облачной сессии. Поставить по-настоящему полезно нужно там, где у тебя постоянно работает Claude Code (свой ноутбук).

## Установка на своей машине

```bash
uv tool install --python 3.13 "headroom-ai[all]"   # рекомендуемый способ (или: pip install "headroom-ai[all]")
```

## Как этим пользоваться — три режима, можно сочетать

**1. Самый простой — обернуть Claude Code одной командой:**

```bash
headroom wrap claude
```

Поднимает локальный прокси и запускает `claude` через него — сразу автоматическое сжатие всего трафика, ничего донастраивать не надо. Отменить:

```bash
headroom unwrap claude
```

**2. Лёгкий — только MCP-инструменты, без фонового прокси:**

```bash
headroom mcp install   # регистрирует Headroom как MCP-сервер для Claude Code, один раз
claude                 # дальше просто обычный запуск
```

Claude получает on-demand инструменты `headroom_compress` (сжать конкретный большой кусок текста), `headroom_retrieve` (вернуть оригинал по хэшу) и `headroom_stats` (статистика экономии). Сжимает не всё автоматически, а по запросу — легковеснее, но без фонового процесса не покрывает весь трафик.

**3. Полный — прокси + MCP вместе** (максимальная экономия):

```bash
headroom proxy --port 8787                              # терминал 1
ANTHROPIC_BASE_URL=http://127.0.0.1:8787 claude          # терминал 2
```

## Проверка и что происходит

```bash
headroom doctor       # health-check: что подключено, что нет
headroom dashboard     # живой дашборд экономии (нужен запущенный прокси)
headroom perf
```

## Когда это реально нужно (по словам авторов)

- Хорошо подходит: пользуешься AI-агентами каждый день и хочешь экономить токены/деньги без правок кода; работаешь сразу в нескольких агентах (Claude, Codex, Cursor...) и хочешь общую память между ними.
- Можно пропустить: если работаешь в песочнице, где локальные процессы вообще не запускаются (как раз наш случай прямо сейчас) — или тебе хватает штатного сжатия контекста одного провайдера.
