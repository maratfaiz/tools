# styles.refero.design — библиотека дизайн-систем для дизайна

## Что это простыми словами

Это не инструмент, а справочник. Представь коллекцию «вскрытых» дизайн-систем реальных продуктов — как будто кто-то разобрал по косточкам сайт Linear или Notion и выложил: вот их точные цвета в HEX, вот шрифты, вот отступы, вот описание характера стиля словами. Ты просто идёшь и подсматриваешь, как выглядит профессиональный, узнаваемый дизайн-стиль, вместо того чтобы придумывать палитру с нуля или брать дефолтные цвета фреймворка.

**Отличие от UI UX Pro Max** (`docs/ui-ux-pro-max.md`): тот skill сам автоматически подбирает стиль под задачу внутри диалога с Claude. Refero — это сайт, на который смотришь сам глазами (или подключаешь как MCP), с примерами именно **реальных знаменитых продуктов**, а не сгенерированных рекомендаций.

[styles.refero.design](https://styles.refero.design) — это каталог из 2000+ дизайн-систем, вытащенных из реальных продуктовых сайтов (Linear, Notion, Apple и т.д.) и упакованных в формат, понятный AI-инструментам (Cursor, Claude Code, v0, Lovable).

Ничего не устанавливается — это обычный сайт, не CLI и не skill. Ниже — как им пользоваться.

## Что там есть

- Готовые дизайн-референсы: цвета, типографика, спейсинг, компоненты, плюс файл `DESIGN.md` с описанием стиля
- Реальные экраны и флоу известных продуктов, с описанием характера стиля (например «midnight precision instrument», «warm cream editorial»)
- Разделы: trending / popular / newest, библиотека AI-промптов для дизайна

## Как пользоваться

### Способ 1 — глазами, вручную (доступно прямо сейчас, ничего подключать не надо)

1. Заходишь на [styles.refero.design](https://styles.refero.design) в браузере
2. В поиске/разделах (trending / popular / newest) находишь стиль, похожий на то, что нужно — например «midnight precision instrument» для строгого dev-инструмента или «warm cream editorial» для блога
3. Открываешь карточку — смотришь скриншоты реальных экранов и файл `DESIGN.md` с точными значениями: HEX-цвета, названия шрифтов, отступы
4. Копируешь эти значения (например, в промпт Claude Code): *«сделай лендинг в такой палитре: primary #1A1A2E, accent #E94560, шрифт заголовков — Space Grotesk»* — дальше Claude верстает уже под конкретные, а не абстрактные цвета/шрифты

### Способ 2 — через Refero MCP (если понадобится автоматизация)

У сервиса есть свой MCP-сервер, который подключается к Cursor, Claude, Windsurf и другим AI-инструментам — тогда агент сам ищет и изучает подходящие дизайн-системы перед тем, как начать верстать, без ручного похода на сайт. Сейчас этот MCP не подключён к текущей сессии — если понадобится, нужно подключить отдельно (детали подключения — на самом сайте, там же где ссылка на MCP).

На момент написания сайт в статусе Beta, цены/платный доступ на сайте не указаны — похоже, каталог просматривается свободно.
