# Remotion Motion Graphics — skill, который учит Claude делать «дорогую» анимацию

Источник: [haidrrrry/claude-remotion-skill](https://github.com/haidrrrry/claude-remotion-skill) (MIT, версия на момент установки — коммит `1dcbe5e`). Лицензия лежит рядом со skill: `.claude/skills/remotion-motion-graphics/LICENSE`.

## Что это простыми словами

В [docs/remotion.md](remotion.md) описан сам Remotion — библиотека «видео из React-кода». Но если просто попросить Claude «сделай видео на Remotion», получится типовой «AI-ролик»: линейные движения, голые фейды, всё появляется одновременно, плоский фон.

Этот skill — **набор правил моушн-дизайна для Claude**. Он не добавляет новых команд, а заставляет Claude, когда речь о видео/анимации, сначала прочитать правила и работать как моушн-дизайнер: пружины вместо линейной интерполяции, каскадное появление элементов, слои (фон → графика → цветокоррекция → зерно), звук, а главное — **после рендера вытащить кадры, посмотреть на них и исправить, и только потом отдавать результат**.

**Пример.** Запрос: «сделай 5-секундную анимацию логотипа». Без skill — логотип плавно проявляется на сплошном фоне. Со skill — логотип въезжает с пружинным «пружиня» + масштабом + фейдом, подпись появляется с задержкой в 4–6 кадров, на фоне дрейфует градиент, сверху зерно и виньетка, есть звуки; перед выдачей Claude рендерит контрольные кадры и сам проверяет, нет ли выезда текста за края.

## Что установлено

Skill скопирован проект-локально, как и остальные (Phoenix и т.д.):

```
.claude/skills/remotion-motion-graphics/
├── SKILL.md                    — workflow (5 шагов) + 10 обязательных правил
├── LICENSE                     — MIT, оригинальный автор @haidrrrry
├── references/
│   ├── motion-patterns.md      — 17 готовых компонентов (фон-меш, цветокор, зерно, Ken Burns, счётчики, переходы, субтитры)
│   └── design-rules.md         — палитры, типографика, темп, звук, чек-лист перед выдачей
└── assets/
    └── theme.ts                — шаблон темы (цвета, easing, spring-пресеты)
```

Открываешь этот репозиторий в Claude Code — skill подхватывается автоматически. Когда тулбокс подключён в другой проект сабмодулем, `.claude/skills/` нужно скопировать/слинковать в проект (так же, как и для остальных skills).

**Не установлено** (намеренно): папка `examples/` из оригинала (~30 МБ с видео и готовыми композициями). Она нужна только как витрина — смотри её в [оригинальном репозитории](https://github.com/haidrrrry/claude-remotion-skill/tree/main/examples). Также не взят `remotion-motion-graphics.skill` — это zip для загрузки в Claude Desktop/Claude.ai (см. ниже).

## Как пользоваться

Ничего вызывать не нужно — skill срабатывает сам по описанию (видео, анимация, интро, Reels/Shorts, логотип, субтитры, «видео выглядит базово»). Примеры запросов:

- «Сделай 5-секундную анимацию логотипа для моего бренда»
- «Моё Remotion-видео выглядит дженерик, исправь»
- «Добавь субтитры, синхронные со словами, к этому клипу»
- «Собери вертикальный Reel-интро в тёмной tech-эстетике»

Как проверить, что skill подхватился: попроси «сделай 3-секундный logo sting». Claude должен **сначала прочитать skill**, а перед выдачей — **извлечь кадры и осмотреть их**. Если видео отдали без проверки кадров — skill не загрузился.

### Рабочий процесс, который skill навязывает Claude

1. **Scope** — длительность, fps (по умолчанию 30), размер (1080×1920 для Reels/Shorts, 1920×1080 горизонт), какие есть ассеты.
2. **Setup** — `npm install remotion @remotion/cli react react-dom`, скопировать `assets/theme.ts` в `src/theme.ts` и подогнать палитру под бренд.
3. **Build** — собрать сцены из паттернов `references/motion-patterns.md`.
4. **Render** — `npx remotion render src/index.ts <CompId> out/video.mp4 --codec h264 --crf 17`.
5. **Verify** (обязательно) — `npx remotion still ... --frame N` на ключевых кадрах, осмотр, правки, повторный рендер.

### 10 правил (кратко)

1. Никакой линейной интерполяции — только пружины/кривые + clamp
2. Вход анимирует 2–3 свойства сразу (прозрачность + сдвиг + масштаб)
3. Всё со сдвигом по времени (3–6 кадров между элементами)
4. Выходы есть и быстрее входов
5. Пять слоёв в каждой сцене: фон → ассеты → графика → цветокор → зерно + виньетка
6. Каждая картинка с Ken Burns; видео — через `<OffthreadVideo>`
7. Статичные элементы «дышат» (микро-движение синусом)
8. Всё время считается от `fps`, без магических чисел кадров
9. Одна `theme.ts`, никаких инлайн-цветов
10. Рендер → кадры → осмотр → исправление → рендер. Не отдавать непроверенное

## Где запускать рендер

Skill — только инструкции, сам рендер идёт через Remotion. В этом репозитории уже есть готовый проект [`remotion/`](../remotion) (см. [docs/remotion.md](remotion.md)): Claude может использовать его как основу — положить `theme.ts` в `remotion/src/` и строить композиции там.

Если Remotion не находит Chromium (песочницы, CI) — skill подсказывает путь: `which chromium google-chrome`, либо `/opt/pw-browsers` (Playwright) и флаг `--browser-executable=<path>`. Если ошибка «Old Headless mode has been removed» — использовать `headless_shell` из Playwright.

## Установка в других местах

Нужно только если используешь skill вне этого репозитория:

**Claude Code, на все проекты (на своей машине):**
```bash
git clone https://github.com/haidrrrry/claude-remotion-skill.git
mkdir -p ~/.claude/skills
cp -r claude-remotion-skill/remotion-motion-graphics ~/.claude/skills/
```

**Claude Code, в один проект:**
```bash
mkdir -p .claude/skills
cp -r claude-remotion-skill/remotion-motion-graphics .claude/skills/
```

**Claude Desktop / Claude.ai:** загрузить файл `remotion-motion-graphics.skill` из оригинального репозитория в *Settings → Capabilities → Skills*.

## Обновление

Skill — снимок на определённый момент. Чтобы обновить: `git clone` оригинала заново и заменить папку `.claude/skills/remotion-motion-graphics/` (не забыть вернуть `LICENSE`, если его не будет в копии — в оригинале он лежит в корне репозитория, а не в папке skill).

## Что учесть

- `ffmpeg` не обязателен: skill предлагает портативный способ проверки через `npx remotion still`.
- Лицензия Remotion (бесплатно до 3 человек / для личного использования) — см. [docs/remotion.md](remotion.md); сам skill — MIT.
- Skill не генерирует картинки и звук. Для ассетов можно связать с Higgsfield ([docs/higgsfield.md](higgsfield.md)); для звука skill предлагает синтезировать минимальный набор SFX скриптом (пример скрипта — `examples/scripts/gen-sfx.mjs` в оригинале).
