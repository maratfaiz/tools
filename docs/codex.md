# Использование в Codex

Codex читает инструкции из `AGENTS.md`, а локальные навыки — из `.agents/skills/`. Символические ссылки на папки навыков поддерживаются. Основа: [официальная документация навыков](https://learn.chatgpt.com/docs/build-skills).

## Открыть сам tools

Клонируй репозиторий и открой его папку как проект в Codex Desktop либо запусти Codex CLI из неё:

```bash
git clone https://github.com/maratfaiz/tools.git
cd tools
codex
```

В `.agents/skills/` доступны Higgsfield, Graphify, UI UX Pro Max, Remotion Motion Graphics, Phoenix и выбранные ECC-навыки разработки. Для ECC используются уже имеющиеся версии из `.claude/.agents/skills/`; остальные ссылки ведут в `.claude/skills/`. Исходники, ресурсы и лицензии остаются вместе. Это доступ к workflow, а не гарантия полной совместимости каждого стороннего скрипта.

Попроси обычными словами или явно укажи `$ui-ux-pro-max`, `$graphify`, `$remotion-motion-graphics`, `$security-review` либо `$higgsfield-generate`. Если новый навык не появился, перезапусти Codex. Папки `.claude/agents`, `.claude/commands`, hooks и settings не становятся настройками Codex.

## Подключить к другому проекту

Само наличие подпапки или сабмодуля `tools/` не открывает его навыки Codex, запущенному из корня родительского проекта. Запусти установщик из клона tools:

```bash
python3 scripts/install-codex-skills.py --target /absolute/path/to/project --dry-run
python3 scripts/install-codex-skills.py --target /absolute/path/to/project
```

Можно подключить только нужные навыки:

```bash
python3 scripts/install-codex-skills.py --target /absolute/path/to/project \
  --skill ui-ux-pro-max --skill remotion-motion-graphics
```

Требуется Python 3.9+. Установщик создаёт относительные ссылки в `<project>/.agents/skills/`, сохраняет существующие файлы и при конфликте прекращает установку до записи ссылок. Повторный запуск безопасен. Он не меняет `AGENTS.md`, настройки Codex, MCP или домашнюю папку и ничего не скачивает.

Не перемещай и не удаляй исходный tools после подключения. Для командной работы удобнее хранить tools сабмодулем внутри проекта и коммитить ссылки вместе с ним; на другой машине нужна поддержка symlink и `git submodule update --init --recursive`. В инструкции родительского проекта можно добавить: «Используй подключённые навыки по задаче; tools — vendored-зависимость, не изменяй её без прямого запроса».

Для отключения удали только созданные ссылки из `.agents/skills/`. Исходные папки в tools сохранятся.

## Внешние сервисы и ограничения

- **Higgsfield:** навыки используют CLI; сначала проверь `higgsfield account status`. MCP, подключённый в Claude, не переносит авторизацию в Codex. Подключение сервера настраивается отдельно по [документации MCP](https://learn.chatgpt.com/docs/extend/mcp?surface=cli). Адрес сервера и способ входа нужно брать у поставщика. Репозиторий не содержит готовой авторизации.
- **ECC / Phoenix:** используются инструкции и справочники. Claude slash-команды и именованные агенты не регистрируются в Codex; workflow выполняется доступными инструментами. Импортированные `allowed-tools` и названия инструментов Claude не дают дополнительных разрешений.
- **Graphify, Headroom:** внешние CLI/прокси требуют отдельной установки. Headroom не включён автоматически; не меняй провайдер или API endpoint Codex ради него без отдельной настройки.
- **Remotion:** навыки не устанавливают npm-зависимости, браузер и ffmpeg. Для готового проекта: `cd remotion`, `npm install`, `npm run lint`, `npm run build`. Рендер проверяется отдельно по кадрам.
- **UI UX Pro Max:** скрипты и данные доступны через ссылку навыка. Старые команды в документации с `.claude/skills/...` можно выполнять из корня tools или использовать путь через `.agents/skills/...`.

Подробные `docs/*.md` сохраняют описание исходных установок для Claude. Для запуска в Codex используй этот документ; заявления там «уже авторизован» и «работает сразу» относятся к прежнему окружению Claude.

## Проверка адаптации

```bash
python3 scripts/check-codex.py
```

Проверяются ссылки и метаданные навыков, установка в путь с пробелами, dry-run, повторный запуск, выбор навыка и защита от перезаписи. Проверка не запускает генерации, внешние сервисы или платные API.
